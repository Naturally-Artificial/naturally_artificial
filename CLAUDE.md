# Naturally Artificial — the site

Static site for the YouTube show Naturally Artificial (host: Sergey Osipov).
Live at https://naturally-artificial.netlify.app. Plain HTML, CSS and JS — no
framework, no npm. `build.py` (Python standard library only) generates
everything that is generated.

## How a change reaches the site

Netlify publishes the repository exactly as committed: a push to `main` is a
deploy, live in under a minute. There is no build step on Netlify. Nothing is
live until it is pushed, and everything pushed is live — so preview locally
first and ask the person before pushing.

A GitHub Action (`.github/workflows/refresh.yml`) runs `build.py` once a day
and commits new episodes, posts and numbers. Because of it, `main` moves on
its own: **always `git pull --rebase` before starting work and before
pushing.**

## Previewing

    python3 -m http.server 8124

then open http://localhost:8124. The contact form only sends on the deployed
site; locally it just shows its success state.

## What is hand-written and what is generated

Hand-written: the body of each page (`index.html`, `show.html`,
`sponsors.html`, `guests.html`, `about.html`, `presskit.html`,
`contact.html`, `privacy.html`, `terms.html`, `404.html`), `css/site.css`,
`js/main.js`.

Generated by `build.py` — edit the script, never the output:

- everything between `<!-- HEAD:start/end -->`, `<!-- CHROME:header:start/end -->`,
  `<!-- CHROME:footer:start/end -->` and `<!-- FEED:…:start/end -->` markers
  (head tags, header, footer, episode lists, the numbers block, home posts);
- the whole `blog/` directory except `blog/slugs.json`;
- `sitemap.xml`, `robots.txt`.

Each page's `<title>` and `<meta name="description">` are hand-written;
canonical, Open Graph and JSON-LD are derived from them.

After editing a page, the header, the footer or `build.py`, re-render:

    python3 build.py --offline   # seconds; needs .cache/feeds.json from a full run
    python3 build.py             # full run: fetches YouTube and Telegram, takes minutes

On a fresh clone there is no cache yet, so the first run must be the full one.
Run the full build in the background and do not edit site files while it runs.

## Do not break

- **`blog/slugs.json`** is the ledger of post addresses. A post's address is
  fixed the first time it is seen, even if the post is edited later. Never
  regenerate or hand-edit it.
- **`assets/tg/`** holds the archived images and videos of Telegram posts.
  Telegram's own links expire; these files are the only durable copy. Never
  delete them.
- **`SITE_URL`** at the top of `build.py` is the one place the site's address
  lives. Change it there when a custom domain arrives, then rebuild.
- **`ASSET_V`** in `build.py` is the cache-busting number on the stylesheet
  and script. Bump it whenever `css/site.css` or `js/main.js` changes, then
  rebuild.
- Internal links are root-relative and end in `.html` (`/show.html`).

## Design rules (from `assets/naturally-artificial-brand-guide.pdf`)

- Colours: black `#101010`, blue `#4BBAFF`, white, grey `#7B7A7D`.
- Type: **Boldonse** for titles and accents, **Inter** for reading, both
  self-hosted in `assets/fonts/`. Boldonse has no Cyrillic — never set it on
  episode or post titles, which may be in Russian.
- The six floral shapes live in `assets/shapes/sprite.svg`.
- The site copy is in English. No third-party fonts or trackers; analytics
  loads only after cookie consent (`ANALYTICS_ID` in `js/main.js`, still empty).
- Cut-out portraits are a JPEG plus a PNG alpha mask applied with CSS `mask`
  (AVIF with alpha renders empty in Chromium).

## Pages

`/` home · `/show` the show and every episode · `/sponsors` · `/guests` ·
`/about` the host · `/blog/` one page per Telegram post · `/presskit` (linked
from the footer only, deliberately not in the main menu) · `/contact` (Netlify
form; accepts `?topic=guest|startup|sponsors|press`; attachment capped at
7 MB because Netlify caps the request at 8) · `/privacy` · `/terms`.

Redirects and headers are in `netlify.toml`. A Netlify redirect target must
not contain a `#fragment`, and a rule that collides with a real file needs
`force = true`.
