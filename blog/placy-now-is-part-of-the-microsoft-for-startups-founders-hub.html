Placy now is part of the Microsoft for Startups Founders Hub, Level 2

The final perk is $150k in Azure credits (initial plan)

Level 2 means we just unlocked the $7,5k needed for OpenAI API and Azure Services, in addition to $5k for GitHub Enterprise, and some other benefits. Not bad

You can also get it. You need:
- Web site. We’ve provided our brand new placy.ai
- Entity. We’ve provided the Placy Ltd Certificate of Registration, pdf

Why does Microsoft give away resources for free? If you are deployed on Azure infrastructure, I think it will be difficult to leave it :)
